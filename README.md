# EasyIsSimple — Open Source Core Examples

Welcome to the public verification repository for **[EasyIsSimple](https://easyissimple.com)**.

EasyIsSimple is a free, privacy-first browser utility toolkit that processes your files, images, and text 100% locally on your device. Your data never touches a server.

## 🔒 Verification Core
This repository does not contain the full proprietary website code, UI assets, or arcade games. Instead, it holds standalone, readable examples of the core privacy engines so developers and security researchers can audit how our local-first tools operate:

* **[Local Image Processing Engine](examples/image-processing-core.js)**: Demonstrates how we resize and convert PNG/JPG/WebP files entirely on the client side using HTML5 Canvas.
* **[Local Base64 Encoding Engine](examples/text-base64-core.js)**: Demonstrates how text is converted to/from Base64 locally using browser APIs.

## 🌐 Live Product
You can run all the tools live at: **[easyissimple.com](https://easyissimple.com)**
